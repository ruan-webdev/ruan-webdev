### Hello Everyone!

My name is Ruan Campos, I'm from Brazil and I graduated in Systems Analysis and Development at FATEC Mogi das Cruzes 💻 I've been in love with technology since I was a child, building different kinds of applications in the most diverse languages, always looking to reach the next level. 🚀

Today I work as a **Data Engineer at Dadosfera**, building robust data pipelines and layered architectures with **dbt**, **Snowflake** and **Airflow**, and applying **Python**, **Machine Learning** and **applied statistics** to turn data into strategic insights and predictive models.

- 🔭 Currently building data pipelines and exploring predictive models with **Prophet** and **Scikit-learn**
- 🌱 Always learning something new about data and machine learning
- 🎓 Degree in Systems Analysis and Development — FATEC Mogi das Cruzes
